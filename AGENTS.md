# Spring

Rails application preloader gem (v4.2.1). Keeps the Rails application running in the background so that commands like tests, rake tasks, and rails console start faster by avoiding repeated boot time.

## Tech Stack

- Language: Ruby (>= 2.7.0)
- Framework: Rails 6.0+ / 7.x integration
- Gem packaging via `spring.gemspec`
- CI: GitHub Actions (`.github/workflows/ci.yml`)
- Tested against Ruby 2.7–3.3+head and Rails 6.1–7.1/edge
